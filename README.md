# 一般教養Note

最終更新: 2026-10-24（都市の路線図を追加しました /
SW `kyoyo-v17` ・ `index.html` の `?v=17`）

一般教養を**クイズ・読み物・1日1問・用語辞典**の4つで身につけるアプリ。
HTML / CSS / JavaScript だけで動き、ビルド不要。通信もゼロ（API を使わない）。
PWA としてスマホのホーム画面に追加でき、完全にオフラインで使える。

## 使い方

| OS | 操作 |
|---|---|
| Windows | `start.bat` をダブルクリック → ブラウザが開く |

同じ Wi-Fi のスマホからも、表示されるアドレス（`http://192.168.x.x:8792/`）で開ける。
ブラウザの「ホーム画面に追加」でアプリとして使える。

## 画面

| タブ | 中身 |
|---|---|
| 📅 今日 | **起動時はこの画面。** 1日1問（日付から決まるので同じ日は同じ問題）・今日の読み物・連続日数 |
| 📖 学ぶ | 8分野のカード（読了の進み具合つき）→ 単元 → 解説カード。読了マーク・⭐・用語から辞典へ。**📚 読書コーナー**・**🗺 地図**・**🍽 マナー**は別アプリを開く |
| ✏️ クイズ | 範囲（全分野／単元別／**弱点のみ**）と問題数を選んで出題。4形式 |
| 🔍 辞典 | 用語・人名で検索 → 解説カードと関連する問題へ |
| 📊 記録 | 連続日数・学習時間・目標バー・14日グラフ・分野別の正答率・苦手な問題 |
| ⭐ 保存 | ⭐を付けたカードと問題 |

クイズは **四択 / ○✕ / 穴埋め / 並べ替え** の4形式。全問に解説が付く。

## 📚 読書コーナー（6つ目の分野）

**3つの本棚・全45作品。** 原文と現代語訳を並べて通しで読めます。巻ごとに要約と読み上げつき。

| 本棚 | 置き場所 | 作品 |
|---|---|---|
| 日本古典文学 | `koten/` | 5作品。竹取物語・土佐日記・枕草子・平家物語・源氏物語（全五十四帖） |
| 日本近現代文学 | `kingendai/` | 30作品。漱石・鴎外・芥川・太宰・賢治ほか。作家の紹介つき |
| 英米文学 | `eibei/` | 10作品。アリス・ホームズ・オズ・若草物語ほか。原文と訳の対照つき |

中身は `学習アプリ` の同名アプリを**そのまま持ってきたもの**です。リーダーの本体（`app.js`）は
3つとも同一で、作品ごとの違いは `data-works.js` に入っています。元から変えたのは2か所だけで、
**「◀」の戻り先を `../#dokusho`（読書コーナー）にしたこと**と、
**`sw.js` のキャッシュ削除を自分の名前の範囲に絞ったこと**です。読書コーナーだけは
**カードもクイズも持たない**ので、`tools/build.js` の分量の検査からは外してあります。

本棚は別の画面として開きます（戻るときは左上の「◀」）。本文は約25MBありますが、
**開いた巻だけを読み込む**作りなので、アプリの起動が重くなることはありません。
通信のない場所で通して読むときは、本棚の設定（⚙）から「まとめて保存」しておきます。
本棚はそれぞれ自分の Service Worker とキャッシュを持つため、`sw.js` は本棚に手を出しません。

## 🗺 地図（7つ目の分野）

**2つの地図・47都道府県・世界186か国。** 白地図を触って位置を覚えます。

| 地図 | 入口 | 中身 |
|---|---|---|
| 日本地図 | `map/#jp` | 47都道府県。県庁所在地・人口・面積・郷土料理・名所と8つの地方区分 |
| 世界地図 | `map/#world` | 186か国。首都・人口・面積・名所と州。出題は押せる大きさの110か国 |
| 都市の路線図 | `rail/#tokyo` | 東京・大阪・名古屋。主要路線と乗換駅の骨格 |

使い方は3つ。**見る**（押すと名前・県庁所在地／首都・人口・面積・郷土料理・名所が出る。
人口と面積には**全体の何位か**も添える。地方で色分けもできる）、
**クイズ**（「地図で探す」＝名前を見て場所を押す／「名前を当てる」＝光っている場所を四択。
間違えたものを覚えていて「苦手なものだけ」を出せる）、**一覧**（押すとその場所に寄る。**地方ごと／人口順／面積順**に並べ替えられる）。

つまんで拡大・引いて移動できます。記録はこの端末の localStorage（`chizu.v1`）だけに残ります。

地図の下には**関係する解説カードへのリンク**があります（日本地図なら「都道府県」「日本の地形と地域性」
「プレートと地形」、世界地図なら「国と首都」「気候区分」「民族と宗教の分布」「地図の読み方」）。
`../#t=<カードid>` の形で、本体の起動処理がそのカードを開きます。

**路線図**（`rail/`）は別のアプリです。駅の座標と「路線が通る駅の並び」だけを持ち、
線は駅をつないで描いています。駅を押すと乗り入れる路線が出て、路線名を押すとその線だけが強調されます。
クイズはデータから自動で作ります（乗換駅の場所を当てる・路線の通る駅を選ぶ・環状運転をする路線を選ぶ）。
**実際の路線図ではなく骨格です。** 主要路線と乗換駅だけを残し、位置関係も間隔も簡略化しています。

地図の形は **Natural Earth**（パブリック・ドメイン）から `tools/make-map.js` が作ります。
人口と面積は、日本が2020年国勢調査と2023年面積調の概数（ツールの中の表に手で持つ）、
世界が Natural Earth の推計と形から計算した概数です。郷土料理と名所は書き下ろしで、
世界の名所は名前を聞いて思い浮かぶ66か国にだけ付けています。

```bash
node tools/make-map.js <admin1.geojson> <world.geojson> <places.geojson>
```

入力は Natural Earth の GeoJSON 3本（`ne_10m_admin_1_states_provinces`・
`ne_50m_admin_0_countries`・`ne_50m_populated_places`）で、合わせて約45MBあるので**配りません**。
生成した `map/data-jp.js`（36KB）と `map/data-world.js`（95KB）だけを公開します。
**形は簡略化してあるので、正確な国境を示すものではありません。** 位置関係を覚えるための図です。

## 🍽 マナー（8つ目の分野）

**4つの単元・図23枚・クイズ42問。** 食事と席次と慶弔の作法を、図を見ながら覚えます。

| 単元 | 入口 | 図 |
|---|---|---|
| 洋食のマナー | `manner/#yoshoku` | テーブルセッティング／使う順／ナイフとフォークの合図／ナプキン／グラス |
| 和食のマナー | `manner/#washoku` | 一汁三菜の配膳／箸の持ち方／嫌い箸／持ち上げてよい器／会席の流れ |
| 席次と立ち居ふるまい | `manner/#sekiji` | 応接室／会議室／和室／車／エレベーター |
| 慶弔ののし袋 | `manner/#keicho` | 水引／袋の折り返し／袱紗／表書きと墨／**宗教で変わる表書き**／**香典袋の書き方**／**和式と洋式の拝礼**／焼香 |

**図の中を押すと、その部分の説明が出ます。** テーブルセッティングのパン皿を押せば
「左が自分のパン皿」、応接室の席を押せば「なぜそこが上座か」が出る形です。

クイズは3種類あります。**図の正しい場所を押す**（上座はどこ・パン皿はどれ）、
**絵を選ぶ**（正しい配膳はどちら・食べ終わりの合図はどちら）、**言葉を選ぶ**（四択）。
間違えたものを覚えていて、「苦手なものだけ」を出し直せます。

図はすべて手描きの SVG で `manner/data-manner.js` の中にあります。外部の画像を使っていないので、
オフラインでも崩れません。色は CSS の class に任せてあり、ライト／ダークの両方で読めます。

**解説カードから図を名指しで開けます。** 5-1 ビジネスマナーと 5-2 冠婚葬祭のカード7枚に
「図で見る」のリンクがあり、`manner/#<単元>&f=<図id>` の形でその図まで飛んで、しばらく枠が光ります。
どのカードからどの図へ飛ぶかは `data-units.js` の `CARD_LINKS` にまとめてあります。

## データを足したら

```bash
node tools/build.js
```

`data/<単元id>.js` を直したら、これを走らせる。やることは3つ。

1. `data/` の原本を分野ごとに結合して `data-<分野>.js` を書き出す
2. カードの `keys` から辞典の索引 `index-term.js` を作り直す
3. データの形式を検査する（カード10枚・クイズ30問か、選択肢が4つか、解説があるか、
   id が重複していないか、`topic` が実在するか、日本語に英単語が紛れていないか）

**検査に失敗すると終了コード 1 を返し、出力は書き換えない。**

## 更新するときの決まり

**`sw.js` の `CACHE` の番号と `index.html` の `?v=` の番号を一緒に上げる。**
上げないと、ローカルで確認するときも古い CSS/JS が使われる。

## 保存されるもの

学習記録はこの端末のブラウザ（localStorage、接頭辞 `kyoyo:`）だけに保存され、端末間で同期しない。
開いていたタブは覚えない（起動時はいつも「今日」から始まる）。
設定の「学習記録を消す」は学習時間・正誤・1日1問の履歴だけを消し、読了と⭐は残す。
