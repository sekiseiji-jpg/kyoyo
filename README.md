# 一般教養Note

最終更新: 2026-10-23（「きょうよう Note」から改称・分野のカードを「学ぶ」の入口にしました /
SW `kyoyo-v5` ・ `index.html` の `?v=5`）

一般教養を**クイズ・読み物・1日1問・用語辞典**の4つで身につけるアプリ。
HTML / CSS / JavaScript だけで動き、ビルド不要。通信もゼロ（API を使わない）。
PWA としてスマホのホーム画面に追加でき、完全にオフラインで使える。

## 使い方

| OS | 操作 |
|---|---|
| Windows | `start.bat` をダブルクリック → ブラウザが開く |

同じ Wi-Fi のスマホからも、表示されるアドレス（`http://192.168.x.x:8792/`）で開ける。
ブラウザの「ホーム画面に追加」でアプリとして使える。

## 画面

| タブ | 中身 |
|---|---|
| 📅 今日 | 1日1問（日付から決まるので同じ日は同じ問題）・今日の読み物・連続日数 |
| 📖 学ぶ | **起動時の入口。** 5分野のカード（読了の進み具合つき）→ 単元 → 解説カード。読了マーク・⭐・用語から辞典へ |
| ✏️ クイズ | 範囲（全分野／単元別／**弱点のみ**）と問題数を選んで出題。4形式 |
| 🔍 辞典 | 用語・人名で検索 → 解説カードと関連する問題へ |
| 📊 記録 | 連続日数・学習時間・目標バー・14日グラフ・分野別の正答率・苦手な問題 |
| ⭐ 保存 | ⭐を付けたカードと問題 |

クイズは **四択 / ○✕ / 穴埋め / 並べ替え** の4形式。全問に解説が付く。

## 収録内容

**5分野40単元・解説カード400枚・クイズ1,200問・辞典の見出し2,509語。**
全単元が同じ分量（カード10枚・クイズ30問）です。

| 分野 | 単元 |
|---|---|
| 🏛 人文科学 | 思想／日本史／世界史／地理／文学／美術・音楽／宗教／心理学 |
| ⚖️ 社会科学 | 政治・統治／経済・金融／法律の基礎／社会学／国際関係／統計の読み方／時事の下地①制度／時事の下地②国際 |
| 🔬 自然科学 | 物理／化学／生物／地学・宇宙／数学／情報・AI／医学・健康／科学史 |
| 🔤 英語 | 教養語彙／語源・接頭辞／イディオム／時事英語／文法の要点／ことわざ／読解／略語 |
| 🏠 暮らしと常識 | ビジネスマナー／冠婚葬祭／ことばの使い分け／四字熟語・故実／暦・年中行事／単位と数字／地図記号・標識／雑学 |

各単元は「全体像」で始まり、8つの項目を1枚ずつ扱い、「よくある誤解を正す」で終わる構成です。

## ファイル構成

| ファイル | 役割 | 公開 |
|---|---|---|
| `index.html` | 画面の骨組み。CSS/JS を `?v=N` 付きで読む | ○ |
| `style.css` | 見た目。CSS 変数でライト/ダーク、640px 以下でスマホ用レイアウト | ○ |
| `app.js` | すべての動作 | ○ |
| `data-units.js` | 40単元の骨格（分野・単元名・作成順）と分野カードの色・紹介文 | ○ |
| `data-jinbun.js` ほか5本 | 分野ごとに結合したカードとクイズ。**`tools/build.js` が作る** | ○ |
| `index-term.js` | 辞典の索引。**`tools/build.js` が作る。手で直さない** | ○ |
| `sw.js` | Service Worker（オフライン対応） | ○ |
| `manifest.webmanifest`・`icon-*.png`・`apple-touch-icon.png` | PWA 設定とアイコン | ○ |
| `data/<単元id>.js` | **データの原本**。1単元1ファイル | × |
| `start.bat` | ローカルサーバー起動（ポート 8792）＋スマホ用アドレス表示 | × |
| `.claude/launch.json` | Claude Code のプレビュー用サーバー設定 | × |
| `tools/build.js` | 結合・索引生成・検査 | × |
| `tools/make-icons.ps1` | アイコン4種の生成（**ASCII のみで書くこと**） | × |
| `構想.md`・`単元一覧.md`・`再現プロンプト.md` | 設計のドキュメント | × |

読み込み順: `data-units.js` → `data-*.js`（5本）→ `index-term.js` → `app.js`。

## データを足したら

```bash
node tools/build.js
```

`data/<単元id>.js` を直したら、これを走らせる。やることは3つ。

1. `data/` の原本を分野ごとに結合して `data-<分野>.js` を書き出す
2. カードの `keys` から辞典の索引 `index-term.js` を作り直す
3. データの形式を検査する（カード10枚・クイズ30問か、選択肢が4つか、解説があるか、
   id が重複していないか、`topic` が実在するか、日本語に英単語が紛れていないか）

**検査に失敗すると終了コード 1 を返し、出力は書き換えない。**

## 更新するときの決まり

**`sw.js` の `CACHE` の番号と `index.html` の `?v=` の番号を一緒に上げる。**
上げないと、ローカルで確認するときも古い CSS/JS が使われる。

## 保存されるもの

学習記録はこの端末のブラウザ（localStorage、接頭辞 `kyoyo:`）だけに保存され、端末間で同期しない。
開いていたタブは覚えない（起動時はいつも「学ぶ」の入口から始まる）。
設定の「学習記録を消す」は学習時間・正誤・1日1問の履歴だけを消し、読了と⭐は残す。
